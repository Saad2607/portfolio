# 🚀 Mohammed Saad Shaikh — Modern Developer Portfolio

A modern, production-grade personal developer portfolio engineered with **React.js, Vite, Tailwind CSS, and Framer Motion**. Showcases full-stack MERN projects, mobile applications built with Flutter & Firebase, industry internship experience, and technical competencies.

## 🌟 Key Architecture & Features

* **⚡ Interactive Developer Hero:** 2-column layout with status indicator, dynamic typewriter headline, live developer IDE terminal widget with runnable diagnostics tabs, and quick resume download.
* **💼 Bento-Grid About Section:** Highlights engineering philosophy, core competencies (Full-Stack MERN, API Security, Database Modeling, Mobile Engineering), and real-time technical focus.
* **🏆 Flagship Project Showcases:** In-depth spotlight presentations for top projects (**FileBridge / SecureVault**, **QuickKart E-Commerce**, and **Pulse Point Blood Bank**) with interactive visual mockups, architecture notes, and technical spec modals.
* **🎛️ Dynamic Project Filtering:** Animated filtering across **All**, **Full Stack**, **React**, and **Mobile** categories with deep-dive technical modals.
* **🛠️ Categorized Skills Matrix:** Interactive tabs across Frontend, Backend, Database & Cloud, Mobile Development, and DevOps tools with dynamic brand icons.
* **⏳ Dual Experience Timeline:** Detailed breakdown of the **Android Developer Internship @ Tenup Software** (Flutter, Firebase, real-time messaging, to-do, and scientific calculator apps) alongside the **Developer Journey** milestones.
* **📊 GitHub & Coding Activity:** Open-source profile showcase with language distribution bars and pinned repository highlights.
* **🌓 Dark & Light Theme System:** Persistent theme switcher with localStorage synchronization and smooth CSS transitions.
* **📬 Interactive Contact Section:** Client-side validated contact form with status feedback, 1-click email copy to clipboard, and direct professional links.
* **📱 100% Responsive & Accessible:** Engineered for all viewports (320px to 4K displays) with zero horizontal overflow, semantic HTML, and ARIA labels.

## 🛠️ Tech Stack & Dependencies

* **Frontend:** React 19, Vite, Tailwind CSS 3.4
* **Animations:** Framer Motion 12, React Type Animation
* **Icons:** React Icons (FontAwesome, SimpleIcons, TablerIcons)
* **Backend Ecosystem:** Node.js, Express.js, MongoDB, REST APIs, JWT Auth
* **Mobile Ecosystem:** Flutter, Dart, Google Firebase / Cloud Firestore
* **Deployment:** Vercel

## ⚙️ Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/Saad2607/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
