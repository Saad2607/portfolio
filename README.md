## 🎨 Modern Glassmorphism UI Architecture

* **🌌 Pure Dark Mode Glassmorphism:** Locked to a permanent, high-contrast dark aesthetic (`#060813`) eliminating washed-out backgrounds.
* **🔮 Ambient Background Refraction Mesh:** 5 large, vibrant glowing orbs (electric indigo, cyan, purple, blue, and emerald with `blur-[150px]`) positioned behind the content so colored light naturally diffuses through frosted glass cards as you scroll.
* **🪟 Multi-Layered Frosted Glass (`.glass-card`, `.glass-pill`):** Engineered with `backdrop-filter: blur(20px)`, translucent dark surfaces, specular border highlights (`border: 1px solid rgba(255, 255, 255, 0.1)`), and inner rim reflections (`inset 0 1px 0 rgba(255, 255, 255, 0.14)`).
* **✨ Smooth Hover Elevations:** Glass panels feature interactive hover physics (`.glass-card-interactive`) with subtle vertical lift, luminous indigo glow, and deeper glass drop shadows.
* **⬆️ Floating "Scroll to Top" Button:** Automatically monitors scroll position and smoothly animates into view once scrolling past `300px`, allowing one-click return to the top from anywhere on the page.

## ⚙️ Environment Variables Setup

For the serverless contact form (`/api/contact`), configure the following in your `.env.local` or Vercel Environment Variables:

```env
# Resend API Key (from https://resend.com)
RESEND_API_KEY=re_your_api_key_here

# Recipient email (where you receive inquiries)
CONTACT_TO_EMAIL=msaadbjs7@gmail.com

# Verified sender address
CONTACT_FROM_EMAIL=Portfolio Contact Form <onboarding@resend.dev>
```

## 💻 Installation & Local Development

```bash
# 1. Clone repository
git clone https://github.com/Saad2607/portfolio.git

# 2. Enter project folder
cd portfolio

# 3. Install packages
npm install

# 4. Start local Vite development server
npm run dev

# 5. Build for production
npm run build

# 6. Run ESLint check
npm run lint
```
